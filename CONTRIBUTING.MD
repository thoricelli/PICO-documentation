# Contributing

Hello there! <br>
First of all thank you for considering to help out with this project.

Feel free to help with existing or creating new documentation on API's or devices by submitting a pull request.

> [!NOTE]
> If you want to create documentation on a new component of the PICO OS, you can do this by creating a new folder at the root of this project and adding this to the table of contents in the main README.

# Documentation

When writing documentation please make sure to at least include:

- **Sources to documentation** <br>
  If you used existing code on Github, local code in this repository, PICO docs, or otherwise then please make sure to link it.
- **When applicable, include the _full_ path of the library or APK you reverse engineered.** <br>
  eg: /system/lib/libeyetrackingclient.pxr.so
- **Caution labels with dangerous function calls or processes.**

> [!CAUTION]
> If a function call may be dangerous to execute or a process may cause damage then please include a warning bubble by using `>[!CAUTION]`
